# MRAK

Веб-сайт для онлайн-записи на услуги детейлинга автомобилей (тонировка, полировка, бронеплёнка).

## Что делает сайт

Пользователь регистрируется, заходит в личный кабинет, выбирает услугу из каталога и записывается на удобную дату и время через календарь. Система автоматически рассчитывает свободные слоты с учётом занятости и длительности услуги.

Клиент может отменять активные записи и просматривать историю выполненных/отменённых записей.

Администратор через отдельную панель управляет каталогом услуг (добавить, редактировать, удалить), просматривает все записи клиентов, меняет их статус (Запланировано / Подтверждено / Выполнено / Отменено) и видит статистику — количество услуг, записей и топ-5 популярных услуг.

## На чём написан

- **Python 3 + Flask** — backend
- **Flask-SQLAlchemy + SQLite** — база данных (`mrak.db`)
- **Werkzeug Security** — хеширование паролей
- **Jinja2 + HTML/CSS** — шаблоны и вёрстка

## Запуск

pip install flask flask-sqlalchemy flask-migrate werkzeug
python app.py
